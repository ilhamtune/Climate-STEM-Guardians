# Installation

## Requirements

- ESP32 Development Board
- Arduino IDE
- DHT22 Sensor
- WiFi Connection

## Steps

1. Install the ESP32 board package in Arduino IDE.
2. Install the DHT sensor library.
3. Open `firmware/esp32/main.ino`.
4. Update your WiFi credentials.
5. Upload the firmware to the ESP32.
6. Open the Serial Monitor to view sensor data.
