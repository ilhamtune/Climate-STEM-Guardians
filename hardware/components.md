# Hardware Components

Climate STEM Guardians is built using affordable and open-source hardware.

## Main Components

- ESP32 Development Board
- DHT22 Temperature & Humidity Sensor
- MQ135 Air Quality Sensor
- Capacitive Soil Moisture Sensor
- Light Sensor
- Wi-Fi Connectivity
- USB Power Supply

The hardware is modular, allowing schools to add or remove sensors depending on their educational needs.
