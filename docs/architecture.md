# Climate STEM Guardians Architecture

## System Overview

The platform consists of four main components:

1. IoT Sensor Nodes
   - ESP32
   - Temperature Sensor
   - Humidity Sensor
   - Air Quality Sensor
   - Soil Moisture Sensor

2. Cloud Platform
   - Secure API
   - Database
   - Data Processing

3. AI Analytics Engine
   - Climate data analysis
   - Pattern detection
   - Learning recommendations

4. Web Dashboard
   - Student Dashboard
   - Teacher Dashboard
   - Environmental Monitoring
